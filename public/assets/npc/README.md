# NPC PNG Assets Specification

Place the transparent PNG sprite files for each duck rival in their respective folders below.

## Folder Structure

```
public/assets/npc/
├── typing/
│   ├── idle.png       (1. Idle breathing / waiting)
│   ├── type.png       (2. Typing on typewriter)
│   ├── talk.png       (3. Talking / adjusting glasses)
│   ├── dance.png      (4. Ballroom dancing)
│   ├── win.png        (5. Celebrating victory)
│   └── lose.png       (6. Defeated / grumpy)
│
├── puzzle/
│   ├── idle.png       (1. Idle with explorer hat)
│   ├── look.png       (2. Examining map / artifact)
│   ├── talk.png       (3. Speaking / explaining clues)
│   ├── dance.png      (4. Ballroom dancing)
│   ├── win.png        (5. Mystery solved joy)
│   └── lose.png       (6. Perplexed / confused)
│
└── cowboy/
    ├── idle.png       (1. Western stance / hat tilt)
    ├── aim.png        (2. Readying finger guns)
    ├── shoot.png      (3. Firing gun / finger pop)
    ├── dance.png      (4. Ballroom country-disco dance)
    ├── win.png        (5. Smug quickdraw victory)
    └── lose.png       (6. Respectful loss / surrendered)
```

## Recommended Specs
- Format: PNG with transparent background
- Dimensions: 172 x 206 pixels (exact)
- Style: Pixel art with crisp scaling (image-rendering: pixelated)
