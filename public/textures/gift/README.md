# 3D Gift Box Textures

Place the 6 square/rectangular image textures for the 3D gift box in this folder:

```
public/textures/gift/
├── front.jpg    (Front face of the gift box)
├── back.jpg     (Back face of the gift box)
├── left.jpg     (Left side of the gift box)
├── right.jpg    (Right side of the gift box)
├── top.jpg      (Top face / lid of the gift box)
└── bottom.jpg   (Bottom face of the gift box)
```

## Recommended Specs
- Format: JPG or PNG
- Resolution: 512x512, 1024x1024, or proportional to box dimensions
- Default Proportions: Width 2.2 x Height 1.6 x Depth 1.8
- Note: If any texture is missing, the 3D scene automatically renders decorative gold ribbon gift wrap as a fallback.
